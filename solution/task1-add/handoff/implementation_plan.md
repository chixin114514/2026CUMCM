# 问题一二维轴向温度对照实验实施计划

> **执行约束：** 具体代码、数值计算和数据整理由 `luna-worker` 完成；根 Agent 只规划、检查和验收。所有新增文件限定在 `solution/task1-add/`，不得改写问题一正式求解器、正式 CSV、`figures/publication/tables/result1.xlsx` 或既有交接文档。

**目标：** 用独立二维轴对称温度实验，判断现有一维径向温度模型忽略轴向导热是否造成显著误差。

**方法：** 计算半域 `0 <= z <= L/2`，在 `z=0` 施加端面对流，在 `z=L/2` 施加轴向对称零通量。采用规则节点网格上的守恒有限体积离散和 Crank--Nicolson 隐式推进；所有物性和附件 1 分段线性插值严格复用问题一口径。现有 `solution/task1/answer/task1_result.csv` 只读作为正式一维基准。

**技术栈：** Python、NumPy、Pandas、SciPy sparse、Matplotlib。

- 创建 `solution/task1-add/handoff/task1_axial_2d_handoff.md`：记录模型、离散、验证、结果和结论边界。

## 2. 基准与输入核验

1. 从 `solution/task1/script/solve_task1.py` 复用参数值、附件路径、列名检查和 `np.interp` 分段线性温度边界口径。
2. 从 `solution/task1/answer/task1_result.csv` 读取正式一维温度结果；验证列、范围、关键时刻和关键半径完整。
3. 只读正式 CSV 作为对照；二维 CN 不依赖正式求解器的时间积分方法。

## 3. 二维守恒求解器

1. 使用半域 `r in [0,0.02] m`、`z in [0,0.125] m`；两方向端节点对应半控制体。
2. 基准网格取 `dr=0.000125 m`、`dz=0.00125 m`、`dt=1 s`，保存 `100,300,600,900,1200,1500,1800 s`。
3. 径向面通量乘圆柱测度 `r_face`；`r=0` 内侧面面积严格为零，不计算 `1/r`。
4. `r=R` 与 `z=0` 的 Robin 通量以边界源项和负对角项进入控制体；`z=L/2` 外侧通量为零。
5. 线性常系数矩阵只装配一次并复用稀疏分解；CN 边界源使用旧、新时刻附件温度的半权平均。

## 4. 数值正确性与敏感性

1. 检查初值、数组形状、有限值、物理温度范围和升温方向。
2. 做绝热端面对照：把二维解的两个 z 边界都设零通量，并与同一径向离散、同一 CN 推进的一维解比较；目标为机器精度量级一致，以验证二维算子、中心奇点和张量装配。
3. 做一次联合加密：`dr=0.000125 m` 保持与正式径向节点一致，取 `dz=0.000625 m`、`dt=0.5 s`；在全部指定 `(r,t)` 的中截面和轴向采样位置比较基准与加密解，输出最大/平均绝对差。
4. 若加密差足以改变“轴向影响是否显著”的判断，继续定位而不是预设结论。

## 5. 数据提取与指标

1. `midplane_1d_vs_2d.csv`：35 个指定 `(t,r)` 点，包含正式一维温度、二维中截面温度、有符号差和绝对误差。
2. `error_statistics.csv`：总体及按时刻汇总最大、平均绝对误差，并记录最大误差位置。
3. `axial_profiles.csv`：在 `r=0` 和 `r=1.5 cm`、7 个关键时刻输出从端面到中截面的轴向温度；至少包含 `z=0、2.5、5、7.5、10、12.5 cm` 及网格上的近端点。
4. `end_effect_range.csv`：计算 `Delta T_z=|T(r,z,t)-T(r,L/2,t)|`。采用 `0.1 degC` 阈值，并以“从端面起最后一个仍满足 `Delta T_z >= 0.1 degC` 的位置（线性插值）”定义传播距离；明确处理全域低于阈值和影响到达中截面的情况。
5. `numerical_sensitivity.csv`：保存基准/加密配置和差异统计。

## 6. 图形与交接

1. 最终只输出一张 `temperature_difference_evidence.png`：上方为五个指定半径的 `|T_2D(z=L/2)-T_1D|` 60 s 居中滚动平均，下方为每个半径全部 1801 个 1 s 原始样本的平均绝对差与最大绝对差柱状汇总。
2. 主面板纵轴为 `×10^-5 °C`，以 `y=10` 标出正式一维 CSV 的 `10^-4 °C` 输出分辨率；下方纵轴为该分辨率的百分比。所有原始差值必须小于 `10^-4 °C`，图形不使用半舍入带或裁剪数据。不绘制湿度，因为原规格禁止二维水分，无法形成合法的 1D/2D 湿度差值证据。
3. 交接文档只回答降维合理性：同时报告中截面最大/平均误差、端部传播距离、中心区均匀性、局部端面效应和敏感性结果；不把二维实验称为正式模型。
