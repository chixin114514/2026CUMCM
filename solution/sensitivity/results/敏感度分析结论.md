## 问题一（守恒 FVM+CN+Picard；关键点 \(T,C\) 最大差）

基准口径：\(\Delta r=5\times10^{-5}\ \mathrm m\)，\(\Delta t=0.25\ \mathrm s\)，Picard 容差 \(10^{-10}\)，线性残差容差 \(10^{-10}\)。

| 参数 | 较粗/另一取值 | 最大 \|ΔT\| / °C | 最大 \|ΔC\| / (kg/kg) |
|---|---|---:|---:|
| `dr_m` | 0.0001 m（较粗） | 1.47e-5 | 2.23e-4 |
| `dr_m` | 0.000025 m（较细） | 3.68e-6 | 5.56e-5 |
| `dt_s` | 0.5 s | 1.47e-7 | 1.94e-7 |
| `dt_s` | 0.125 s | 3.70e-8 | 4.86e-8 |
| `picard_tol_C` | 1e-8 / 1e-12 | 0 | 1.87e-14 / 3.91e-14 |
| `linear_residual_tol` | 1e-8 / 1e-12 | 0 | 0 |

结论：空间步长是主控因素，水分浓度比温度更敏感；网格加密与时间步减半均单调降低差异，\(\Delta t=0.25\ \mathrm s\) 时间误差约 \(10^{-7}\)，远小于四位小数报告精度；Picard 与线性残差容差在 \(10^{-8}\sim10^{-12}\) 内对四位小数结果无影响。

| `time_step_early_s` | 2 / 0.5 s | 0 | <8.1e-10 |
| `STABLE_START_S` | 7200 s | **+0.0556** | 6.87e-4 |
| `STABLE_START_S` | 10800 s | +0.0095 | 1.18e-4 |
| `event_tol_s` | 1 / 0.01 s | +6.5e-5 / -1.9e-5 | 0 |
| Picard 容差 | ±100× | 0 | <2e-11 |

结论：收缩模型下 \(t_{\rm dry}\) 对时间步长几乎完全不敏感（\(\Delta t=0\)），对空间网格已收敛；最敏感项仍是稳定段起点（约 \(\pm0.06\) h）。事件定位精度在 0.1 s 已足够，放宽到 1 s 仅带来约 0.00007 h 偏差。

## 总体判断

1. **必须报告/继续加密的**：问题三的径向网格 `n_intervals`（N=1600 为基准），以及问题三、四共用的 `STABLE_START_S` 稳定段起点（模型外推假设）。这两项量级在 \(10^{-2}\)–\(10^0\) h，是 \(t_{\rm dry}\) 不确定度的主要来源。
2. **可忽略的**：内部时间步（长期/前段）、Picard 容差、线性残差容差、事件定位精度，均在 \(10^{-6}\) h 及以下，远小于四位小数报告精度。
3. **问题一**空间步长为唯一可见影响因素；**问题二** 以 \(N=1600\)、\(\Delta t=1\ \mathrm s\) 为正式基准，时间步与网格加密差异均已低于四位小数报告精度。
